# CNIT-28000-FA26-Group-3
Welcome to the MacroMaker repository! This project is designed by Andrew Connolly & Trey Greene for our CNIT 28000 class at Purdue University.
This program is currently only supported for Windows 10/11. There are not plans to port the program to macOS or Linux.
To install and run the program, please see the instructions below.

NOTE: As of version 0.5, the program is intended to be run as an executeable file, not as a Python script. Modifications to the program may be
required to retain functionality as a Python script.

Step 1: Download the release from the MacroMaker github repository.

Step 2: Select a location for the install folder (NOTE: MacroMaker does not have an installer, simply move the .exe file to a folder where you want the program to be).

Step 3: Open the MacroMaker executable file. The .exe file will generate a .db file within the same directory.

User Tutorial / FAQ

Q: How do I create a macro?
A:
1. Open the MacroMaker exe file
2. Click on "Add Macro"
3. Click on "Ok"
4. Press all desired hotkeys and then release all at the same time (e.g. if you want shift+l+p, hold down shift, l, and p then release)
5. Verify that the program read your desired keys correctly, click "Yes" if correct, click "No" to retry, and click "Cancel" to exit
6. Enter a filepath you wish to open.
7. Click "Ok", your macro is now active and ready for use!

Q: How do I enable MacroMaker to launch on startup?
A: Click on the "settings" button, and then make sure "Launch on Startup" is checked.
